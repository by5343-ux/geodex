## 인터넷에 올리는 방법

깃허브 계정만 있으면 무료입니다. **명령어를 쓰지 않고 웹에서만** 할 수 있습니다.

### 1. 저장소 만들기

1. [github.com](https://github.com) 로그인 → 오른쪽 위 **+** → **New repository**
2. **Repository name** 에 `geodex` 입력
3. **Public** 선택 (무료로 공개하려면 필수)
4. **Create repository**

### 2. 파일 올리기

1. 만들어진 저장소 화면에서 **uploading an existing file** 누르기
2. 이 폴더 안의 **파일 전부**를 끌어다 놓기
   - `index.html`, `manifest.json`, `sw.js`, 아이콘 4개, 워크북 2개, `README.md`
   - **`.nojekyll` 파일도 반드시 포함** (점으로 시작해 숨은 파일로 보일 수 있음)
3. 아래 **Commit changes** 누르기

> `.nojekyll` 이 없으면 깃허브가 파일을 임의로 가공해 깨질 수 있습니다.

### 3. 공개 설정

1. 저장소 위쪽 **Settings** → 왼쪽 메뉴 **Pages**
2. **Source** 를 `Deploy from a branch` 로
3. **Branch** 를 `main`, 폴더는 `/ (root)` 로 두고 **Save**
4. 1~2분 기다리면 위쪽에 주소가 나옵니다

```
https://아이디.github.io/geodex/
```

이 주소가 수업에서 쓸 주소입니다.

## 학생 기기에서 쓰는 방법

### 아이패드·아이폰

1. **사파리**로 주소 열기 (크롬이 아니라 사파리여야 합니다)
2. 아래 **공유 버튼** → **홈 화면에 추가**
3. 홈 화면 아이콘으로 실행하면 주소창 없이 **전체 화면**으로 열립니다

### 안드로이드

1. **크롬**으로 주소 열기
2. 주소창 오른쪽 **⋮** → **앱 설치** 또는 **홈 화면에 추가**

### 인터넷이 끊겨도

한 번 열어 두면 파일이 기기에 저장되어 **인터넷 없이도 실행**됩니다.
수업 전에 미리 한 번씩 열어 두시면 학교 무선망이 불안정해도 문제없습니다.

## 고칠 때

`index.html` 을 고쳐 다시 올리면 됩니다. 저장소에서 파일을 누르고
연필 아이콘으로 바로 편집하거나, **Upload files** 로 덮어쓰면 됩니다.

학생 기기에 옛 파일이 남아 있을 수 있으니, 크게 고쳤을 때는
`sw.js` 안의 `geodex-v1` 을 `geodex-v2` 처럼 바꿔 주세요. 그러면 새로 받아 갑니다.
